# E2E Harness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `make agent-e2e` run real FreeSWITCH call scenarios in Docker handsfree, with LAN Linphone support via IP.

**Architecture:** Fix single `internal` sofia profile + LAN ACL + published SIP/RTP ports; extend stdlib `sip_endpoint.py` with scenario modes that log JSONL; make `seed.py` create ext/ring-group/conference/IVR fixtures and `verify.py` emit machine-readable JSON; upgrade mock ESL to stateful for Tier-1 offline tests.

**Tech Stack:** Python 3.14 stdlib SIP (asyncio UDP), FreeSWITCH mod_sofia/mod_xml_curl/mod_xml_cdr + fs_cli + ESL, Docker Compose overlay, pytest + httpx, lxml.

**Spec:** `docs/superpowers/specs/2026-09-25-e2e-harness-design.md`

## Global Constraints

- Never put api + FreeSWITCH in same container; separate services on one compose bridge.
- FS image must be pinned by digest, not `:latest`.
- SIP domain for automated tests stays `test.example.com`; LAN phones may use IP `192.168.100.82` as proxy/identity — backend IP fallback in `app/freeswitch/xml_router.py:161-171,196-204` already maps IP → `test.example.com` data, do not break it.
- Directory SIP password default `1234` (see `app/freeswitch/xml_builder.py:28`).
- Do NOT `reload mod_xml_cdr` at runtime; restart container instead.
- Valkey xml cache TTL 60s — seed must invalidate after writes.

- [ ] **Step 3: Write minimal implementation**

In `sip_endpoint.py` keep `Phone` class, add:
- `SUPPORTED_MODES = {"answer","busy","no-answer","dtmf","originate","conference-join"}`.
- `build_invite(target)` mirroring `build_register` but `INVITE sip:<target>@<DOMAIN>` with SDP body offering PCMU.
- `dtmf_payload(digit)` returning RFC2833 bytes (event code map `0-9,*,#,A-D`).
- `handle_invite` branch on `SIP_MODE`: `busy` → send `486 Busy Here`; `no-answer` → `180` only then timeout; `dtmf` → answer then `await send_dtmf(SIP_DTMF)` via RTP (best-effort UDP to negotiated port, log only); `conference-join` = answer + hold 15s.
- `originate_loop`: after REGISTER, `await asyncio.sleep(2); await send_invite(SIP_TARGET)` once, log `invite-sent`.
- Every event also `append_jsonl({"t": ..., "ext": EXT, ...})` to `/tmp/phone-<EXT>.jsonl`.
- Bind SIP port `0` (ephemeral) when `SIP_PORT` unset to avoid host clash; keep `5060` only inside containers via `SIP_PORT` env.
- Never break existing `answer` path (default).

Compose: add `phone1003` (`SIP_EXT=1003 SIP_MODE=busy`), `phone1004` (`SIP_EXT=1004 SIP_MODE=dtmf SIP_DTMF=1`); existing 1001/1002 stay `answer`. All `depends_on: freeswitch`.
